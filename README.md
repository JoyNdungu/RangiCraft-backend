# RangiCraft — Backend

## REST API for RangiCraft — the African market color palette generator.

🌍 Live API → [rangi-craft-backend.vercel.app](https://rangi-craft-backend.vercel.app/)

🎨 Frontend → [rangi-craft-frontend.vercel.app](https://rangi-craft-frontend.vercel.app/)


## 📸 Overview

This is the Express.js backend for RangiCraft. It handles saving and retrieving color palettes generated by users, connected to a MongoDB Atlas database.

## ✨ Features


Save palettes — store generated palettes with full metadata

Fetch palettes — retrieve all saved palettes sorted by latest

Get single palette — fetch a specific palette by ID

Delete palettes — remove a saved palette

Serverless-ready — optimized MongoDB connection for Vercel deployment

CORS configured — locked to frontend origin

## 🚀 Getting Started


Prerequisites

Node.js v18+


npm or yarn


MongoDB Atlas account (free tier works)

## Installation

Clone the repo

```
git clone https://github.com/JoyNdungu/RangiCraft-backend.git
cd RangiCraft-backend
```

Install dependencies

```
npm install
```

Environment Variables

Create a .env file in the root:

```
envPORT=5000
MONGO_URI=mongodb+srv://youruser:yourpassword@cluster0.xxxxx.mongodb.net/rangicraft
NODE_ENV=development
```


Running Locally

```
npm run dev
```

Server runs at http://localhost:5000

Test it:

```
curl http://localhost:5000/

# → { "message": "🎨 RangiCraft API is running" }
```
